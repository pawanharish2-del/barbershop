# Barber Furniture

A handcrafted vintage barbershop interior clone and showcase website built with pure HTML5, CSS3, and modern responsive design.

## Features

- **Vintage Aesthetic:** Modeled after authentic 1900s artisanal barbershop interiors with serif typography, gold accents (`#d89028`), and dark aged tones.
- **Full-Width Interactive Header:** Responsive navigation bar with full-width hover submenus and active state indicators.
- **Multi-Page Architecture (9 Pages):**
  1. `index.html` — Homepage featuring brand story, collection overviews, and 3-column product cards.
  2. `barber-furniture.html` — Barber furniture / Barberunits showcase with detailed line breakdowns.
  3. `barber-chairs.html` — Heavy-duty vintage barber chairs showcase.
  4. `retail-furniture.html` — Retail display counters and cabinets.
  5. `buying.html` — Global distributors directory (Benelux, Germany, USA).
  6. `projects.html` — Masonry gallery of completed barbershop installations.
  7. `contact.html` — Contact form, physical showroom info, and virtual tour link.
  8. `vintage-barberset.html` — Product detail page for the Barberset 'Vintage' collection.
  9. `the-royal-series.html` — Product detail page for 'The Royal Series' barber chairs.
- **Rich UI Elements:**
  - Double white-bordered vintage image frames (`.double-frame`).
  - Floating sticky mail button (`.floating-mail`).
  - Scroll-to-top button (`.scroll-top`).
  - 4-column dark footer with catalogue download card and Instagram photo grid.
- **Fully Responsive:** Fluid layouts optimized for desktop (`1180px`), tablet (`980px`), and mobile (`600px`).

## Getting Started

No build tools or package managers required. Simply clone the repository and open `index.html` in any modern web browser or serve it with a local static server:

```bash
# Clone the repository
git clone https://github.com/pawanharish2-del/barbershop.git

# Navigate to project directory
cd barbershop

# Optional: Run a local static server
python -m http.server 8000
```
